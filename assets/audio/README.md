# Audio

Each game page has audio buttons wired to `generateAudioClip()` in `game.js`.
That function creates spoken narration in the browser with the Web Speech API.

When you have final recorded files, use this pattern:

`game-slug-intro.mp3`
`game-slug-lesson.mp3`
`game-slug-mission.mp3`
`game-slug-success.mp3`
