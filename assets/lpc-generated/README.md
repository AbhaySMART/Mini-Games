Kind Kingdom LPC-generated assets

These transparent pixel sprites are a curated subset from the open-source
Universal LPC Spritesheet Character Generator:
https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator

They are used for Kind Kingdom character bodies, clothing, hair, capes, crowns,
and wings. The full upstream credits and license files are included here as:

- CREDITS.csv
- LICENSE

If more LPC layers are added later, update this folder and keep the credits file
with the project.
